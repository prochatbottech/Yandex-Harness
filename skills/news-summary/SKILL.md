# Скилл: Сводка новостей и данных

## Назначение
Этот скилл предписывает агенту собирать данные по теме, фильтровать главное и формировать структурированный отчёт.

## Шаги выполнения:
1. Загрузи исходные данные или веб-страницы с помощью `web_fetch`.
2. Извлеки ключевые факты:
   - Даты и события
   - Количественные показатели
   - Ключевые выводы
3. Сформируй итоговый файл в Markdown формате с разделами:
   - `# Сводка`
   - `## Ключевые тезисы`
   - `## Детали`
4. Сохрани файл отчёта через `fs_write` в `workspace/summary.md`.
