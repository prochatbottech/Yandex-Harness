# Скилл: Анализ таблиц CSV с Python

## Назначение
Этот скилл инструктирует агента, как анализировать числовые данные и файлы CSV с помощью Python скриптов.

## Шаги выполнения:
1. Изучи структуру файла с помощью `fs_read` (первые строки).
2. Напиши Python-скрипт для вычисления агрегированных метрик (сумма, среднее, группировки).
3. Запусти код через `run_code`.
4. Результаты анализа оформи в читаемую таблицу или Markdown-отчет.
