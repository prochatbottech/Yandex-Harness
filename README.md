# Harness Desktop

> Открытый десктоп-харнесс для ИИ-агентов на моделях Яндекса (YandexGPT, Alice AI LLM) и локальных открытых моделях.

## Возможности
- 🧠 Работа с моделями Яндекса через OpenAI-совместимый интерфейс и локальными моделями (Ollama, llama.cpp, vLLM).
- 🔄 Полный прозрачный агентный цикл (ReAct / Tool calling) с контролем шагов.
- 🛡️ Безопасность и политики доступа (Policy Engine): подтверждение чувствительных действий пользователем.
- 🔌 Поддержка протокола MCP (Model Context Protocol) и кастомных плагинов/инструментов.
- 💾 Локальное хранилище состояния и памяти (SQLite + Markdown).
- 🖥️ Нативный и легковесный десктопный клиент на Tauri 2 (Rust) + React.
